This repo's architecture is modelled on that library: the dispatcher-plus-
sub-skill layout, the frontmatter contract, the pre-delivery checklist framing,
the one-canonical-home rule, and the verify-don't-assume discipline around
platform facts.

**No text was copied.** [`knowledge/higgsfield-ai-prompt-skill-teardown.md`](knowledge/higgsfield-ai-prompt-skill-teardown.md)
is an original description of how that repo is structured and which of its
patterns are worth reusing. Their prose, templates, vocabulary files and
Python tooling remain theirs.

If you want the actual Higgsfield prompt library, install theirs — it is far
deeper than anything here, and [`skills/higgsfield/SKILL.md`](skills/higgsfield/SKILL.md)
routes to it rather than trying to replace it.
