# Workspace

Local working area. Contents are git-ignored — nothing here is committed.

| Folder | Use |
|---|---|
| `input/` | Briefs, scripts, references, plates to read from |
| `output/` | Everything produced for you — prompt packs, shot breakdowns, reports |
| `processed/` | Inputs already consumed. Files get **moved** here, never deleted. |

The rule that matters: deliverables go in `output/`, not the repo root, and a
finished input gets relocated rather than removed.
